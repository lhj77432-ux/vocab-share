# DSE 背单词（vocab-share）

香港 DSE English 词汇学习站（可分享）。

**线上地址：** https://lhj77432-ux.github.io/vocab-share/

## 架构

**网站本身即通道**：输入 → 生成结果 → 展示。无单独连接器／插件／玩页。底层调用对访客隐藏。

| 功能 | 行为 |
|------|------|
| 搜索 | 一次返回英译 + 中译 + 例句 |
| 学习 | 本站服务推荐今日学什么，每词下方附造句 |
| 今日推荐 | 可设每天 N 个新词（不重复已推）；例句中译挖空 + ABCD 选义 + 推荐理由（仅 DSE） |
| 归类 | 本站服务归类；打开词条再生成内容 |
| 测验 | 连续多题：新词 + 挖空中译 + ABCD；答完自动下一题 |
| 造句 | 本站服务造句／点评 |

本地 DSE 核心词表约 500+ 词。推荐不准编假词。尚未接入 vocab-train 小模型权重。

## 本地

```bash
npm install
npm run dev
```

进度存在浏览器 localStorage。分享用「分享」页生成的链接（`?share=` 编码词表）。

## 账号

邮箱＋密码登录：站点导航「账号登录」（`#/account`）。未登录不可翻转学习卡／连续词义测验。忘记密码由管理员代发重置信息到注册邮箱（网站不自动发信）。
